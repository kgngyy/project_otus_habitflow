# User Stories (ТЗ проекта)

> Сформулированы на этапе планирования с помощью AI.

## Роли
- **Гость** — неавторизованный посетитель.
- **Пользователь** — авторизованный пользователь.

## User Stories

**Как гость, я хочу:**
1. Зарегистрироваться по e-mail и паролю, чтобы создать аккаунт.
2. Войти через Google (OAuth2), чтобы не запоминать пароль.
3. Войти через Яндекс ID, чтобы использовать привычный аккаунт.
4. Восстановить доступ, если забыл пароль (подтверждение e-mail в Supabase).

**Как пользователь, я хочу:**
5. Создать привычку (название, цвет, дни недели), чтобы планировать рутину.
6. Редактировать привычку, чтобы исправить настройки.
7. Удалить привычку, чтобы убрать ненужную.
8. Отмечать привычку выполненной на сегодня, чтобы фиксировать прогресс.
9. Видеть прогресс за сегодня (сколько из запланированных выполнено).
10. Смотреть статистику за 7 дней, чтобы оценивать регулярность.
11. Выйти из аккаунта.

## Критерии приёмки (definition of done)
- Данные изолированы по пользователям (RLS) — видно только своё.
- Все ошибки показываются понятным сообщением, а не «сырым» стектрейсом.
- Состояния загрузки (спиннер/«Загрузка…») и пустые состояния обработаны.
- Интерфейс адаптивен (корректно выглядит на телефоне и десктопе).
