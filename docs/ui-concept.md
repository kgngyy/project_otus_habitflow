# Концепция интерфейса (UI)

> Сгенерирована с помощью AI на этапе дизайна (Text-to-UI).

## Экраны

### 1. Страница входа (LoginPage)
- Заголовок, переключатель «Вход / Регистрация».
- Поля e-mail и пароль с валидацией.
- Кнопки «Продолжить с Google» и «Продолжить с Яндекс ID».
- Сообщения об ошибках и подсказка «проверьте почту» после регистрации.

### 2. Главная (HomePage)
- Прогресс-бар «выполнено X из Y сегодня».
- Форма добавления привычки: название, выбор цвета (6 вариантов),
  выбор дней недели (Вс–Сб).
- Список привычек: отметка «✓», название, кнопки редактирования/удаления.

### 3. Статистика (StatsPage)
- Бар-чарт выполнения за 7 дней (Пн–Вс).
- Общий процент выполнения за неделю.

## Дизайн-решения
- Цветовая схема: фиолетовый акцент (#aa3bff), светлая/тёмная тема (CSS-переменные).
- Адаптив через медиазапросы (`max-width: 1024px`), флекс-раскладка.
- Простые, крупные интерактивные элементы — удобно на мобильных.
